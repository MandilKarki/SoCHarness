Implemented: three navigation groups (Investigate, Agent Lab, Operate), legible
sidebar, contextual page titles, accessible off-canvas mobile navigation, a
toggleable agent console, less redundant catalog chrome, light/dark design tokens,
responsive tool/runtime grids, reduced-motion support, account/passkey pages,
recovery sign-in and device setup instructions. Existing guide, evidence, session,
tool, approval, matrix and runtime actions use the same backend contracts.

Technology decision: the frontend is now React + TypeScript + Vite, using official
shadcn/ui Radix components and Tailwind CSS. Component-owned state replaces legacy
DOM-mutating scripts in the workspace, catalogs, lab, tour and authentication pages.
The standalone architecture atlas remains HTML. Python and SQLite stay unchanged.
React Aria was an alternative, not an additional dependency. No external asset CDN,
paid template, analytics service or remote font is introduced here.
https://ui.shadcn.com/docs/changelog/2026-02-blocks
https://react-aria.adobe.com/quality
https://vite.dev/guide/

Theme preference and guide step numbers are browser-local. Credentials, telemetry,
and chat content are not added to localStorage. Source strings render as React text,
never raw HTML. NDJSON parsing preserves split UTF-8 and trailing records. Polling
and streaming merge by sequence ID; success requires a recorded completion event.
Benchmark cohorts are explicitly labeled: severity is a lab review priority, not
a detection verdict. No new SDK features or live provider verification is claimed.
